# ゲーム準備

1. プレイ順序を決定し、それに応じて各プレイヤーに初期資金を配布します。
- 1: 5pt
- 2: 6pt
- 3: 7pt
- 4: 8pt
2. 各プレイヤーは山札から3枚を引いて手札とします。労働者を2人ずつ受け取ります。
3. 初期配置として、学校、鉱山、採石場、大工(プレイ人数-1)を共通場に配置します。

# ゲーム本編

スタートプレイヤーから時計回りに順番にターンを行います。
ラウンド中でスタートプレイヤーが変わってもプレイ順は変わりません(次のラウンドから変わります)。

## ターンの流れ

プレイヤーは労働者を一人ずつ自分専用会社または共通会社に配置します。明記されていない限り一つの会社には一人の労働者しか配置できません。
配置された会社に応じたアクションを実行します。建設、建物カードのドロー、消費財カードのドロー、資金の獲得、労働者の獲得などがあります。

山札がなくなった場合、捨て札をシャッフルして新たな山札とします。
家計の資金は銀行資金とは区別されており、基本的に給料の支払いでしか増加しません。家計から金額を取得するアクションは、家計の資金を上回っている場合発動できず、そのための労働者配置もできません。

### 建設

建設においては、左上の数字に応じたコストとして、手札の建物カードまたは消費財カードを捨てます。

### 労働者の追加

労働者を追加する場合、明記されていない限り次のターンから配置可能となります。ただし、給料の支払いはそのラウンドから発生します。

## ラウンド終了

### 手札制限

ラウンド終了時に手札が5枚を超えている場合、超過分を捨て札にします。

### 労働者の回収と給料の支払い

1. 労働者を配置先から回収します。
2. ラウンドごとに決められた給料を家計へ支払います。
金額が不足している場合、自分専用の建物を売却(資産価値分の金額を銀行から受け取り、共通場に配置)して、給料を支払います。その際、過剰に売却することはできません。
3. 建物を売却しても給料が支払えない場合、1ptにつき罰則カードを1枚受け取り、銀行から家計へ支払います。この罰則カードはゲーム終了時点で1枚につき-3ptとなります。

### ラウンドの進行

ラウンドカードを表にして共通場に加えます。

# ゲーム終了

9ラウンド終了時に、各プレイヤーは以下の得点を合計します。

- 金額の合計
- 自分専用の建物の資産価値の合計
- 建物に記載された追加得点の合計
- 罰則カードの合計(マイナス点)
- (メセナ、グローリーの場合) 勝利点の合計(3枚ごとに10点、3枚に満たない分は1枚ごとに1点)
